
# CSV 合并工具（基于 java）
为什么这样做更好？
分发极其简单：你只需要把这个 .html 文件发到工作群里，说一句“用浏览器打开”，任何人都能用。

安全性：所有操作都在同事自己的浏览器内存中完成，数据不会上传到任何服务器（包括你的电脑），完全符合公司数据保密要求。

兼容性：代码中处理了 \uFEFF (BOM)，这样下载下来的 CSV 文件，同事直接用 Excel 打开不会乱码（这是之前 Python 版本如果不加 utf-8-sig 会遇到的问题）。

你可以先自己在本地试一下，如果有特定的 CSV 格式（比如包含逗号的单元格）导致解析不对，告诉我，我可以微调一下解析逻辑。
